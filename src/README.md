# VST3-/DOSBox-X-Adapter

Hier entsteht **genau ein** Echtzeit- und Audio-Adapter für den gepinnten DOSBox-X-AWE32-Fork mit originaler Creative-DOS-Runtime.

Der Ordner ist absichtlich noch frei von einer vermeintlich funktionierenden Ersatz-Engine. Erst tatsächliche Build-, MIDI-, ROM/SF2-, Audio- und Recall-Nachweise gelten als abgeschlossen.
